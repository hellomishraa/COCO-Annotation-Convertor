# COCO Annotation Converter

A simple web-based tool for converting and processing **COCO-format annotations**. The project provides a React frontend with a Python backend to make annotation conversion easier and more accessible.

## Features

* Upload and process COCO annotation files
* Convert annotation formats for computer vision workflows
* Simple web-based interface
* Python backend for annotation processing
* React-based frontend

## Project Structure

```text
COCO-Annotation-Convertor/
├── backend/       # Python backend and annotation processing
├── frontend/      # React frontend
└── README.md
```

## Tech Stack

* **Frontend:** React
* **Backend:** Python
* **Data Format:** COCO Annotations

## Getting Started

### Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend

```bash
cd frontend
npm install
npm start
```
